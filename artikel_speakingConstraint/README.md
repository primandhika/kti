# Riset Speaking

Starter pack penulisan artikel jurnal Q2 tentang speaking.

## Struktur

- `main/`: bagian-bagian naskah artikel.
- `data/`: catatan sumber data penelitian.
- `references/`: artikel dan sumber pustaka.
- `template/`: template jurnal tujuan.
- `scripts/`: skrip pengolahan data dan dokumen.
- `outputs/`: naskah hasil kompilasi atau siap kirim.
- `_rev/`: catatan revisi.

## Status

Proyek telah diinisialisasi. Judul kerja saat ini adalah **Riset Speaking** dan dapat diganti kemudian.

## Inti Projek

menekankan bahwa constraint berupa "no powerpoint/visual aid" dapat meningkatkan kemampuan bicara, kemudian dibarengi juga dengan perencanaan yang matang khas metakognitif berdampak kesiapan dan mengurangi kecemasan berbicara, bisa tanpa/dengan media yang mendukung. usahakan  bersumber dari /dist/data/ - ditujukan untuk jurnal scopus Q2.
