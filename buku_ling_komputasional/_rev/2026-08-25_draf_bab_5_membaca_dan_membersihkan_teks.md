# Catatan Revisi: Draf Bab 5 Membaca dan Membersihkan Teks

## Berkas yang dibuat
- `main/05-membaca-dan-membersihkan-teks.md`

## Fokus isi
1. Menjembatani Bab 4 tentang *Google Colab* ke praktik awal analisis teks yang lebih nyata.
2. Menjelaskan cara membaca data teks dari file `.txt` dan kolom teks dari file `.csv`.
3. Memperkenalkan *lowercasing*, normalisasi dasar, penghapusan tanda baca, penghapusan karakter tertentu, serta perapian spasi dan baris.
4. Menjaga semua contoh tetap kontekstual dengan pembelajaran bahasa, korpus mini, puisi, artikel, dan data tulisan pembelajar.
5. Menambahkan output dan penjelasan untuk setiap contoh kode agar konsisten dengan aturan proyek.
6. Menekankan bahwa pembersihan teks harus selalu mengikuti tujuan analisis, bukan dilakukan secara membabi buta.

## Dasar rujukan utama
- McEnery dan Hardie untuk pentingnya ketelitian data dalam kerja korpus
- Meyer untuk orientasi analisis korpus yang berbasis data nyata
- O’Keeffe, McCarthy, dan Carter untuk pembelajaran berbasis data bahasa
- Widodo et al. untuk relevansi data korpus pada konteks pembelajaran bahasa
- dokumentasi resmi Python untuk operasi string dan struktur data dasar
