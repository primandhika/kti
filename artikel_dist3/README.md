# Enhancing Speaking Skills and Metacognitive Awareness through a Microlearning-Based Multimedia Platform

Arsip kerja untuk proyek: **Artikel Jurnal Ilmiah**.

## Deskripsi Singkat
Pengaruh platform microlearning berbasis teknik Feynman terhadap keterampilan berbicara dan kesadaran metakognitif mahasiswa menggunakan metode Mixed-method quasi-experimental (R&D dengan field test pre-post control group).

## Cara Menggunakan Repositori Ini
1. Tulis naskah di folder `main/`.
2. Simpan referensi PDF di folder `references/`.
3. Gunakan folder `_rev/` untuk mendokumentasikan setiap masukan dari reviewer/promotor.

## Standar Penulisan
Proyek ini mengikuti aturan internal yang didefinisikan dalam `PROJEK.md`.
