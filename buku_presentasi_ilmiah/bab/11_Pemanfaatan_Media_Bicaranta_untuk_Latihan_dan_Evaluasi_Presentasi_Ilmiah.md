# Bab 11 Pemanfaatan Media Bicaranta untuk Latihan dan Evaluasi Presentasi Ilmiah

## Pengantar Bab

Bab ini membahas pemanfaatan media Bicaranta sebagai sarana pendukung latihan keterampilan berbicara dan evaluasi presentasi ilmiah.

## Tujuan Pembelajaran

- Mengenali posisi Bicaranta sebagai media pendukung pembelajaran berbicara.
- Menjelaskan potensi Bicaranta untuk latihan presentasi ilmiah.
- Mengaitkan Bicaranta dengan strategi microlearning dan metakognitif.
- Menyusun skenario penggunaan Bicaranta secara etis dan terarah.
