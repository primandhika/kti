# Proyek Buku: Mahir Presentasi Ilmiah

Folder ini disiapkan untuk pengembangan buku *Mahir Presentasi Ilmiah dengan Strategi Microlearning dan Metakognitif*.

- Pedoman penulisan: `ATURAN_BUKU.md`
- Halaman cover: `COVER.md`
- Data penerbitan: `INFO_PENERBITAN.md`
- Rencana isi dan bab: `RENCANA_BAB.md`
- Panduan kompilasi DOCX: `README_COMPILE.md`
- Script kompilasi DOCX: `compile_docx.py`
- Catatan revisi substantif: folder `_rev` saat diperlukan

Daftar isi rinci, naskah bab, dan bagian pendukung buku akan disusun berdasarkan rencana bab yang telah disepakati, termasuk bab penutup tentang pemanfaatan media Bicaranta.
